1.2 计算机网络基础

1.2.1 带宽

  • 定义：网络通信线路所能传送数据的能力，即网络信道的容量。
  • 单位：bps（比特每秒）
  • 区分概念：
    • 带宽：最大传输能力（水管粗细）
    • 吞吐量：实际传输数据量（实际流过的水量）
    • 时延：数据从一端到另一端花费的时间

1.2.2 5G（第五代移动通信技术）

  • 全称：5th Generation
  • 音标：/ˈfɪfθ ˌdʒenəˈreɪʃn/
  • 性能目标：高数据速率、低时延、低能耗、低成本、高系统容量、大规模设备连接

三大应用场景：

缩写全称中文音标特征
eMBBenhanced Mobile Broadband 增强移动宽带/ɪnˈhænst ˈməʊbaɪl ˈbrɔːdbænd/大带宽（快）
uRLLCultra-Reliable and Low Latency Communications 超高可靠超低时延通信/ˈʌltrə rɪˈlaɪəbl ænd ləʊ ˈleɪtənsi kəˌmjuːnɪˈkeɪʃnz/低时延+高可靠（准）
mMTCmassive Machine Type Communications 海量机器类通信/ˈmæsɪv məˈʃiːn taɪp kəˌmjuːnɪˈkeɪʃnz/海量连接（多）

uRLLC 实现关键技术：

  • 短帧结构：采用迷你时隙（mini-slot），缩短空口传输时延
  • 快速反馈：同一时隙内完成 HARQ（混合自动重传请求）反馈
  • 多点/多站重传：用户设备同时连接多个基站，多链路保障可靠性

1.2.3 软件定义网络（SDN）

  • 全称：Software Defined Networking
  • 音标：/ˈsɒftweə dɪˈfaɪnd ˈnetwɜːkɪŋ/
  • 核心思想：将网络设备的控制平面与数据平面分离开来

三层架构：

层级功能类比（快递中心）
应用层提出网络需求业务部门提需求
控制层维护全局视图，下发流表规则中央调度中心
基础设施层（数据转发层）仅按流表规则执行数据转发分拣员手脚

三类接口：

接口连接对象作用标准化情况
南向接口控制层 ↔ 数据转发层下发流表规则有标准（如 OpenFlow ）
北向接口应用层 ↔ 控制层上层应用调用网络资源尚无统一标准
东西向接口控制器 ↔ 控制器控制器集群间状态同步、协同用于解决单点故障

1.2.4 集中式结构

  • 定义：以大型机/小型机为中心的计算模式，所有计算、存储、管理集中在主机，终端（哑终端）仅负责输入输出
  • 优点：管理维护方便、安全性高、数据一致性好
  • 缺点：主机负担重、单点故障、扩展性差
  • 对比演进：客户机/服务器（C/S）模式将处理功能分布到两端，增强灵活性和扩展性

1.4.7 数据仓库与OLAP

数据仓库四大特征：面向主题、集成、相对稳定、反映历史变化

对比维度OLTP（联机事务处理）OLAP（联机分析处理）
全称On-Line Transaction Processing On-Line Analytical Processing
音标/ˌɒn laɪn trænˈzækʃn ˈprəʊsesɪŋ//ˌɒn laɪn ˌænəˈlɪtɪkl ˈprəʊsesɪŋ/
面向日常操作员管理决策者
特点当前、细节、频繁更新历史、汇总、只读查询

OLAP多维分析操作：

  • 切片：取出某一维度的一层
  • 切块：取出一子集
  • 钻取：从汇总深入细节
  • 旋转：改变观察视角

1.4.8 数据挖掘常见方法

  • 分类：判断属于哪一类
  • 聚类：相似的分成一组
  • 关联规则：发现物品间联系（如啤酒与尿布）
  • 回归分析：预测连续数值
  • 异常检测：找出异常值

第3章 信息技术服务规划

3.1 诺兰模型（信息系统发展阶段模型）

诺兰将计算机信息系统的发展道路划分为六个不可跳跃、波浪式前进的阶段：

阶段特征类比（家庭用车）
初始阶段引入计算机，少数人使用买第一辆车，只敢在附近开
蔓延阶段各部门大量采购，各自为政人手一辆，各自瞎跑
控制阶段管理层集中管控IT预算和项目家庭会议，严格限制用车
集成阶段打通数据孤岛，系统整合给现有车装GPS，统一调度
数据管理阶段重视数据资产的分析利用分析行车数据优化出行
成熟阶段IT与业务融合，驱动创新成为出行达人，创造新价值
