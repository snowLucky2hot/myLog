1.2 计算机网络基础

1.2.1 带宽

  • 定义：网络通信线路所能传送数据的能力，即网络信道的容量。
  • 单位：bps（比特每秒）
  • 区分概念：
    • 带宽：最大传输能力（水管粗细）
    • 吞吐量：实际传输数据量（实际流过的水量）
    • 时延：数据从一端到另一端花费的时间

1.2.2 5G（第五代移动通信技术）

  • 全称：5th Generation
  • 音标：/ˈfɪfθ ˌdʒenəˈreɪʃn/
  • 性能目标：高数据速率、低时延、低能耗、低成本、高系统容量、大规模设备连接

三大应用场景：

缩写全称中文音标特征
eMBBenhanced Mobile Broadband 增强移动宽带/ɪnˈhænst ˈməʊbaɪl ˈbrɔːdbænd/大带宽（快）
uRLLCultra-Reliable and Low Latency Communications 超高可靠超低时延通信/ˈʌltrə rɪˈlaɪəbl ænd ləʊ ˈleɪtənsi kəˌmjuːnɪˈkeɪʃnz/低时延+高可靠（准）
mMTCmassive Machine Type Communications 海量机器类通信/ˈmæsɪv məˈʃiːn taɪp kəˌmjuːnɪˈkeɪʃnz/海量连接（多）

uRLLC 实现关键技术：

  • 短帧结构：采用迷你时隙（mini-slot），缩短空口传输时延
  • 快速反馈：同一时隙内完成 HARQ（混合自动重传请求）反馈
  • 多点/多站重传：用户设备同时连接多个基站，多链路保障可靠性

1.2.3 软件定义网络（SDN）

  • 全称：Software Defined Networking
  • 音标：/ˈsɒftweə dɪˈfaɪnd ˈnetwɜːkɪŋ/
  • 核心思想：将网络设备的控制平面与数据平面分离开来

三层架构：

层级功能类比（快递中心）
应用层提出网络需求业务部门提需求
控制层维护全局视图，下发流表规则中央调度中心
基础设施层（数据转发层）仅按流表规则执行数据转发分拣员手脚

三类接口：

接口连接对象作用标准化情况
南向接口控制层 ↔ 数据转发层下发流表规则有标准（如 OpenFlow ）
北向接口应用层 ↔ 控制层上层应用调用网络资源尚无统一标准
东西向接口控制器 ↔ 控制器控制器集群间状态同步、协同用于解决单点故障

1.2.4 集中式结构

  • 定义：以大型机/小型机为中心的计算模式，所有计算、存储、管理集中在主机，终端（哑终端）仅负责输入输出
  • 优点：管理维护方便、安全性高、数据一致性好
  • 缺点：主机负担重、单点故障、扩展性差
  • 对比演进：客户机/服务器（C/S）模式将处理功能分布到两端，增强灵活性和扩展性

1.4.7 数据仓库与OLAP

数据仓库（Data Warehouse ，DW /ˈdeɪtə ˈweəhaʊs/）：一个面向主题的、集成的、相对稳定的、反映历史变化的数据集合，用于支持管理决策

四大特征详解：

特征英文音标教材要点
面向主题Subject-Oriented /ˈsʌbdʒɪkt ˈɔːrientɪd/按管理对象（客户、产品、供应商）综合归类组织；主题按决策分析对象抽取
集成Integrated /ˈɪntɪɡreɪtɪd/抽取、筛选、清理、综合；统一单位/字长/内容，消除同名异义、异名同义
相对稳定Non-Volatile /nɒn ˈvɒlətaɪl/以查询为主一般不修改，定期加载刷新；可省去完整性保护与并发控制
反映历史变化Time-Variant /taɪm ˈveəriənt/保存长时间历史数据，是不同时刻数据库快照的集合，支持趋势分析

四层体系结构：数据源 → 数据的存储和管理 → OLAP服务器 → 前端工具（报表/查询/分析/数据挖掘工具）

三种数据仓库模型：

模型英文音标含义
企业仓库Enterprise Warehouse /ˈentəpraɪz ˈweəhaʊs/收集全企业各主题所有信息，跨多个功能范围
数据集市Data Mart /ˈdeɪtə mɑːt/企业范围数据的子集，限于选定主题，服务特定部门
虚拟仓库Virtual Warehouse /ˈvɜːtʃuəl ˈweəhaʊs/操作型数据库上视图的集合
对比维度OLTP（联机事务处理）OLAP（联机分析处理）
全称On-Line Transaction Processing On-Line Analytical Processing
音标/ˌɒn laɪn trænˈzækʃn ˈprəʊsesɪŋ//ˌɒn laɪn ˌænəˈlɪtɪkl ˈprəʊsesɪŋ/
面向日常操作员管理决策者
特点当前、细节、频繁更新历史、汇总、只读查询

OLAP多维分析操作：

  • 切片：取出某一维度的一层
  • 切块：取出一子集
  • 钻取：从汇总深入细节
  • 旋转：改变观察视角

9.1 信息安全的基本属性

信息安全的基本属性（教材官方口径为五大属性）：

属性英文音标含义生活类比典型威胁
保密性Confidentiality /ˌkɒnfɪˌdenʃiˈæləti/信息不被未授权者获取金库只有授权人员能进窃听、泄露
完整性Integrity /ɪnˈteɡrəti/信息不被未授权修改（篡改/删除/插入）账本不得篡改篡改、伪造
可用性Availability /əˌveɪləˈbɪləti/合法用户需要时可访问和使用ATM 机 7×24 可取款DoS/DDoS 拒绝服务
可控性Controllability /kənˌtrəʊləˈbɪləti/责任主体可对信息传播及内容具有控制能力行长能管控资金流向非法内容传播
不可否认性Non-Repudiation /ˌnɒn rɪˌpjuːdiˈeɪʃn/行为人事后不能否认自己的操作签字画押，事后赖不掉抵赖发送/接收

记忆线索：前三项即国际通称的 CIA 三要素 （控制非授权主体），后两项（可控性、不可否认性）控制已授权主体也不能乱来。三个核心属性各对应一类典型攻击——泄密破坏 C、篡改破坏 I、拒绝服务破坏 A。

CIA 之外的扩展属性（可作了解）：可审查性（行为可追踪追溯）、真实性、可靠性、隐私性、可生存性。

往年真题：

【系规练习题】信息安全的基本属性中，确保信息不被未经授权者泄漏的是（　）
A. 完整性　B. 可用性　C. 保密性　D. 不可否认性
答案：C（保密性 = Confidentiality，防止信息泄露）
【系规练习题】信息安全管理的 CIA 三要素指的是（　）
A. 一致性、可用性、完整性　B. 保密性、有效性、可用性　C. 一致性、可用性、有效性　D. 保密性、完整性、可用性
答案：D（CIA = Confidentiality 保密性 + Integrity 完整性 + Availability 可用性）

9.2 信息安全的主要技术与措施

安全技术体系按纵深防御 思路分五层设防（从外到内）：

层次技术核心作用生活类比
网络层防火墙 内外网屏障，本质是访问控制产品小区门禁
入侵检测 IDS 防火墙的合理补充，监控违反安全策略的行为巡逻保安
VPN 公用网上建加密隧道专属地下通道
主机层漏洞扫描/主机加固修补系统与数据库漏洞定期体检
应用层身份认证（口令/PKI证书/生物识别）确认「你是谁」出示身份证
访问控制（DAC/MAC/RBAC）确认「你能干什么」门禁卡权限分级
数据层加解密（对称+非对称）传输与存储保密密码信封
数字签名+哈希校验防篡改 + 抗抵赖签字画押+骑缝章
全局安全审计（日志+行为审计）事后追溯、评估策略有效性监控录像
备份与容灾恢复保住最后一道底线（可用性）异地存档

9.2.1 四种访问控制模型

模型全称控制者特点典型场景
DAC自主访问控制（Discretionary Access Control）客体所有者灵活但安全性低Linux 文件 rwx 权限
MAC强制访问控制（Mandatory Access Control）系统按安全标签安全性最高、配置复杂军事/政府系统
RBAC基于角色的访问控制（Role-Based Access Control）角色管理员企业最常用OA/ERP 权限体系
Rule-BAC基于规则的访问控制（Rule-Based Access Control）规则引擎动态判定防火墙/VPN 策略

MAC 的两个经典模型：BLP 模型 保保密性（规则「上读下写」）、Biba 模型 保完整性（规则「下读上写」）。

往年真题：

【2023年下半年·上午】常见的访问控制机制有四种，其中不包括（　）
A. 自主访问控制　B. 基于角色的访问控制　C. 基于风险的访问控制　D. 强制访问控制
答案：C（干扰项常用「基于风险」「基于身份」「基于属性」，正统四种为 DAC/Role-BAC/Rule-BAC/MAC）

9.2.2 密码技术与国密算法

类别原理国际算法国密算法
对称加密加解密同一把钥匙，快，适合大量数据AES、DESSM4
非对称加密公钥加密私钥解密，慢，适合密钥交换/签名RSASM2
哈希（单向）不可逆，验完整性SHA、MD5SM3

记忆口诀：SM2 签名（非对称）、SM3 校验（哈希）、SM4 加密（对称）。
